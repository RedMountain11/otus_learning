# Лабораторная работа. Просмотр таблицы MAC-адресов коммутатора
## 1. Топология
![Схема](https://github.com/RedMountain11/otus_learning/blob/main/homeworks/homework2/Screen/Лабораторная%202%20-%20топология.jpg?raw=true)

|Устройство|Интерфейс|IP-адрес|Маска подсети|
|----------|--------|--------|--------|
|S1|VLAN1 |192.168.1.11|255.255.255.0|
|S2|VLAN 1|192.168.1.12|255.255.255.0|
|PC-A|NIC|192.168.1.1|255.255.255.0|
|PC-B|NIC|192.168.1.2|255.255.255.0|


## 2. Задачи
1. Подключить сеть в соответствии с топологией.
2. Настроить узлы ПК.
3. Выполнить инициализацию и перезагрузку коммутаторов.
4. Настроить базовые параметры каждого коммутатора.
5. Записать МАС-адреса сетевых устройств.
6. Просмотреть таблицу МАС-адресов коммутатора S2.
7. Очистить таблицу МАС-адресов коммутатора S2 и снова отобразить таблицу МАС-адресов.
8. С компьютера PC-B отправит эхо-запросы устройствам в сети и просмотреть таблицу МАС-адресов коммутатора.

## 3. Решение
- Шаг 0: сделано. Ссылка на лабу [здесь](./config'n'lab)
- Шаг 1. Запишите МАС-адреса сетевых устройств.
  - Назовите физические адреса адаптера Ethernet.
    - MAC-адрес компьютера PC-A: 0090.2BAA.EC0A
    - MAC-адрес компьютера PC-B: 00D0.BA2A.84A1

  - Подключитесь к коммутаторам S1 и S2 через консоль и введите команду show interface F0/1 на каждом коммутаторе. Назовите адреса оборудования во второй строке выходных данных команды (или зашитый адрес — bia).
    - МАС-адрес коммутатора S1 Fast Ethernet 0/1: 00e0.8fa4.2701
    - МАС-адрес коммутатора S2 Fast Ethernet 0/1: 0090.0c75.7801

- Шаг 2 Просмотрите таблицу МАС-адресов коммутатора S2. В привилегированном режиме EXEC введите команду show mac address-table и нажмите клавишу ввода:
```
S2#show mac address-table
          Mac Address Table
-------------------------------------------

Vlan    Mac Address       Type        Ports
----    -----------       --------    -----

   1   00e0.8fa4.2701    DYNAMIC     Fa0/1
S2#
```
Записаны ли в таблице МАС-адресов какие-либо МАС-адреса? Ответ: да, записаны. Но только MAC одного sw.

Если вы не записали МАС-адреса сетевых устройств в шаге 1, как можно определить, каким устройствам принадлежат МАС-адреса, используя только выходные данные команды show mac address-table? Работает ли это решение в любой ситуации? Ответ: метода не знаю. Как это узнать?

- Шаг 3 Очистите таблицу МАС-адресов коммутатора S2 и снова отобразите таблицу МАС-адресов.

  - a. В привилегированном режиме EXEC введите команду clear mac address-table dynamic и нажмите клавишу Enter.
S2# clear mac address-table dynamic
  - b. Снова быстро введите команду show mac address-table.
    - Вопросы:
            Указаны ли в таблице МАС-адресов адреса для VLAN 1? Указаны ли другие МАС-адреса?
            Через 10 секунд введите команду show mac address-table и нажмите клавишу ввода. Появились ли в таблице МАС-адресов новые адреса? Ответ: указан 1 MAC на порту fa0/1, не пропадал. Других не было.

- Шаг 4. С компьютера PC-B отправьте эхо-запросы устройствам в сети и просмотрите таблицу МАС-адресов коммутатора.

  - a. На компьютере PC-B откройте командную строку и еще раз введите команду arp -a.
    - Вопрос:
Не считая адресов многоадресной и широковещательной рассылки, сколько пар IP- и МАС-адресов устройств было получено через протокол ARP? Ответ: ни одного
  - b. Из командной строки PC-B отправьте эхо-запросы на компьютер PC-A, а также коммутаторы S1 и S2. От всех ли устройств получены ответы? Если нет, проверьте кабели и IP-конфигурации. Ответ: от всех.
  - c. Подключившись через консоль к коммутатору S2, введите команду show mac address-table.
Вопрос:
Добавил ли коммутатор в таблицу МАС-адресов дополнительные МАС-адреса? Если да, то какие адреса и устройства?
Ответ: Да, появились. Появилися MAC PC-A, MAC виртуального LAN (интерфейса VLAN 1 у S1), MAC интерфейса fa0/1 у S1, MAC PC-B.
```
S2#show mac address-table
          Mac Address Table
-------------------------------------------

Vlan    Mac Address       Type        Ports
----    -----------       --------    -----

   1    0004.9a92.550a    DYNAMIC     Fa0/1
   1    0090.2baa.ec0a    DYNAMIC     Fa0/1
   1    00d0.ba2a.84a1    DYNAMIC     Fa0/6
   1    00e0.8fa4.2701    DYNAMIC     Fa0/1
```

На компьютере PC-B откройте командную строку и еще раз введите команду arp -a.
  - Вопрос:
Появились ли в ARP-кэше компьютера PC-B дополнительные записи для всех сетевых устройств, которым были отправлены эхо-запросы?
Ответ: дополнительные записи появились. Почему-то PC-B видит MAC у VLAN-интерфейсов S1, S2.
```
C:\>arp -a
  Internet Address      Physical Address      Type
  192.168.1.1           0090.2baa.ec0a        dynamic
  192.168.1.11          0004.9a92.550a        dynamic
  192.168.1.12          0000.0c78.bba8        dynamic
```
